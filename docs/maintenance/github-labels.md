To make maintenance of the site easier long term, please make sure issues are tagged correctly.
Currently we use only a small number of thematic labels since the issue content tells us what kind of issue it is anyway.

### Issue types

| Type | Use |
| --- | --- |
| `Addition` | New directory or calendar entry |
| `Correction` | Existing content is stale or wrong |
| `Bug` | Site or updater behavior is broken |
| `Feature` | New feature suggestions |

### Labels

| Label | Use |
| --- | --- |
| `community` | Additions to the communities page |
| `event` | Changes to the events page |
| `publication` | Blogs, books, or YouTube channels |
| `resource` | Resource or ecosystem listing |
| `ui` | Templates, styles, UI configuration etc. |
| `updater` | Metadata updater changes |
| `documentation` | Improvements or additions to documentation |
| `duplicate` | This issue or pull request already exists |
